# 原生功能迁移清单

范围：先建立可扩展的双端原生工程，并迁移最基本的浏览、分组清理和状态存储。次要功能按以下阶段递进，不一次性重写发布版的全部功能。

“已接入”表示源代码已连接到真实平台 API，仍待构建与真机验收；不是已发布或验收通过。

| 功能 | 当前状态 | 实现或边界 |
| --- | --- | --- |
| 独立原生工程、资源、图标、构建入口 | 已建立 | SwiftUI / Compose；手动 GitHub workflow |
| 照片 / 视频 / 我的三 Tab | 已接入 | iOS 系统 TabView；Android Compose 胶囊 |
| iOS Liquid Glass、Android 原生玻璃 | 已接入 | 系统材质与 Kyant Backdrop 1.0.6；待真机看效果 |
| 主题、中英文、安全区 | 已接入 | 系统/浅/深主题，语言跟随系统；大字号待真机检查 |
| 完整、部分、拒绝授权 | 已接入 | PhotoKit / MediaStore；设置返回刷新 |
| 相册与封面、分页媒体网格 | 已接入 | 每页 90 项，后台读取元数据 |
| 照片/视频分组清理 | 首批已接入 | 最新优先，5/10/15/20 项；标记、保留、撤销 |
| 视频播放 | 首批已接入 | 当前项单播放器，Android 6 秒/12 MB 缓冲上限 |

| 删除统计、历史记录、完成页 | 下一批 P0 | 使用实际删除结果，不伪造 iOS 文件大小 |

| 旧版数据导入、正式覆盖升级 | 发布门槛 | 预览独立安装，不读写旧版数据 |

## P1：效率和媒体能力

| 功能 | 迁移要求 |
| --- | --- |
| 全局分析缓存、排队、暂停/取消/续跑 | 指标按资产共享；衍生结果按相册；不重复解码 |
| 相似照片、精确重复、连拍、低质量 | 保留 2 分钟时间窗、Hamming <= 8、尺寸/大小及 Live Photo 例外 |
| 大文件、旧截图、视频重复建议 | 使用真实指标；建议会话不能覆盖暂停的正式会话 |
| 分析进度、低电量与内存适配 | CPU/解码并发 1-3；省电开关及进入提示 |
| 收藏、照片/视频查看器 | 网格/列表、缩放、分享、删除标记检查 |
| Live Photo 播放、静音、云端读取状态 | 公共 PhotoKit API；明确区分本地可读和 iCloud-only |
| EXIF、位置与地址解析 | 保留拍摄元数据，不使用私有 PhotoKit 大小字段 |
| 分类到相册、新建相册、取消分类 | Android 保留时间戳和稳定 ID；iOS 使用集合语义 |
| Android 回收站、恢复、永久删除 | 30 天策略与原元数据保全；预览当前使用系统直接删除 |
| iOS 最近删除说明 | 使用系统删除；不承诺通过公开 PhotoKit 枚举或恢复“最近删除” |
| 手动语言选择、媒体播放设置 | 首批已支持语言跟随系统 |
| 日志导出、缓存清理 | 错误可定位，缓存不与用户数据混淆 |

## P2：工具和扩展

| 功能 | 迁移要求 |
| --- | --- |
| 摄影画像、存储图表、历史趋势 | 使用经验证的统计数据 |
| 图片/视频压缩 | 默认生成副本，原文件删除另行确认 |
| 提醒时间段、通知权限 | 平台通知 API，保留用户选择 |
| 更新检查、更新日志、发布渠道 | 正式版本号和下载资产统一；原生预览不进入旧版更新通道 |
| 捐赠、反馈、关于与第三方许可界面 | 保留现有项目入口 |
| Android 8-10 兼容性 | 单独评估权限与删除路径，预览最低 Android 11 |

## 下一步顺序

1. 维护者构建并检查第一批原生主流程。
2. 完成年/月筛选、会话队列与统计。
3. 接入分析、建议、收藏、查看器和低电量适配。
4. 完成回收站、分类、工具和旧数据导入。
5. 完成功能对照及升级验收后，再替换现有发布版。
