# 原生界面规范

目标是统一信息结构和视觉层级，同时保留两端的系统交互。

## 页面结构

- 照片 / 视频 / 我的三个 Tab，照片与视频使用相同布局。
- 首页直接显示相册、真实封面、数量、每组数量和开始/继续清理。
- 相册内为自适应缩略图网格；清理为全屏媒体和底部保留/标记操作。
- 组末展示每一项的保留/删除状态，只有组确认才会请求系统删除。
- 未迁移功能保留在功能清单，不在界面中显示空入口。

## 平台实现

| 语义 | iOS | Android |
| --- | --- | --- |
| 根导航 | SwiftUI TabView | Compose 三项胶囊导航 |
| 玻璃 | iOS 26 系统 Liquid Glass / glassEffect | Kyant Backdrop 1.0.6 Compose 库 |
| 低版本材质 | 系统 TabView、regularMaterial | Android 11/12 不透明主题表面 |
| 设置 | 原生 Form / Picker | Material 控件，保持相同字段顺序 |
| 返回 | 系统返回、侧滑，清理页关闭 | 系统返回、返回按钮，清理页关闭 |
| 配色 | 系统语义色、蓝色主操作 | 对应的中性表面、蓝色主操作 |

照片封面采用 8pt/dp 圆角；浮动清理工具区采用 24pt/dp 层级。系统控件保留系统形状，这些尺寸不是苹果规定的固定数值。避免将整个页面做成浮动卡片。

采用系统字体，正文和控件跟随系统字号，不强制限制文字缩放。列表和网格适应宽度；Android 底栏实际测量高度后增加滚动内容的末尾间距，滚动区域仍延伸到玻璃下方。iOS 使用系统安全区。Android 每组数量选项在大字号下自动换行。

这份规范和源代码尚不代表经过真机视觉验收。验收时检查：iOS 26 原生材质、Android 13+ 滚动时背景折射、浅深主题、最大字号、横屏安全区和系统返回。
